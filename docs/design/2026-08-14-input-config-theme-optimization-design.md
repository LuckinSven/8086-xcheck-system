# XCheck 输入、配置与主题优化设计

## 目标

在不引入登录、密钥管理服务或额外数据库的前提下，统一攻击日志与访问日志的上传能力，将依赖 API 配置和认证测试开放到前端，并将视觉主题调整为微步情报社区风格。

## 输入与解析

- 页面只区分“攻击日志”和“访问日志”两个业务名称，不用文件选择器限制扩展名。
- 两类日志均接受 CSV、XLS、XLSX、LOG、JSONL 和 ZIP；后端根据扩展名选择解析器，拒绝真正无法识别的内容。
- 攻击日志从 `srcAddress` 列或 JSON Lines 的 `srcAddress` 字段提取；访问日志从 `访问源 IP` 列提取。
- ZIP 可混合包含 CSV、XLS、XLSX、LOG 和 JSONL，沿用成员数、解压总量与路径穿越保护；ZIP 内文件按任务业务类型提取对应字段。
- Excel 默认读取活动工作表，空 IP 单元格进入输入错误记录；大文件继续按只读模式迭代行。

## API 配置与测试

- `GET/PUT /api/settings` 管理白名单 URL、微步 URL、微步 API Key 及现有限速项，写入本地 SQLite `settings` 表并即时应用。
- API Key 不在读取接口中回显；空值表示保留已有 Key，另提供显式清除开关。
- `POST /api/settings/test-whitelist` 使用 `8.8.8.8` 发起真实白名单请求，验证 HTTP 与返回结构。
- `POST /api/settings/test-threatbook` 使用 `8.8.8.8` 发起真实微步请求，验证密钥、HTTP 和业务响应码。
- 测试响应只返回成功状态、耗时与安全消息，任何密钥都不得写入响应或诊断。

## 前端与主题

- 设置页分为“白名单接口”“微步接口与认证”“查询限速”三块，支持保存与分别测试连接。
- 新建任务页面去掉 `accept` 扩展名限制，显示统一的支持格式说明。
- 主题采用微步情报社区近似风格：深海军蓝导航、明亮情报蓝主操作、青绿色成功态、浅蓝灰工作区；保留当前响应式布局和高风险红色语义。

## 验收

- CSV/XLS/XLSX 以及 ZIP 内对应文件对两种任务类型都能正确提取 IP。
- 上传接口接受支持格式，不再按业务类型拒绝扩展名。
- 前端能保存两类 API 配置、Key，并能看到真实认证测试结果。
- API Key 读取与测试响应不泄露明文。
- 后端测试、前端测试、类型检查、生产构建与 Docker 健康检查全部通过。
