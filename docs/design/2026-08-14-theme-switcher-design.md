# XCheck 皮肤切换设计

## 目标

在现有工作台右上角增加轻量皮肤选择器，把微步情报社区红色系设为首次访问的默认皮肤，同时保留当前情报蓝，并提供护眼青绿和三套额外配色。皮肤切换不依赖登录或后端配置，选中结果保存在当前浏览器。

## 交互设计

- 顶栏右侧将服务状态与“皮肤”按钮并排展示。
- 点击按钮打开六套皮肤色卡；当前皮肤显示名称、三色预览和选中标识。
- 选择色卡后立即切换全站颜色并关闭菜单。
- 首次访问使用“微步社区红”；后续访问恢复浏览器上次选择。
- 无效或不可用的本地存储值安全回退到默认皮肤。
- 小屏幕保留皮肤入口，隐藏现有服务状态以节省空间。

## 配色目录

1. 微步社区红（默认）：深酒红导航、情报红主操作、暖灰白工作区。
2. 情报蓝：完整保留优化前的深海军蓝、明亮情报蓝和青绿成功色。
3. 护眼青绿：低饱和鼠尾草绿、暖白背景和柔和边框，降低长时间查看的视觉刺激。
4. 暗夜紫：深紫导航、蓝紫主色和冷灰白工作区。
5. 琥珀沙金：深褐导航、琥珀主色和沙色工作区。
6. 雾海青蓝：深青导航、海蓝主色和雾白工作区。

## 技术设计

- `theme.ts` 维护主题 ID、显示信息、默认值和本地存储边界。
- 根元素的 `data-theme` 属性决定皮肤；CSS 自定义属性承载导航、主色、文本、表面、边框和反馈色。
- `:root` 直接声明默认红色变量，避免脚本初始化前出现蓝色闪烁。
- 现有样式中的关键硬编码颜色改为语义变量；失败、危险等状态继续保持红色语义，不随品牌主色混淆。
- 本地存储键为 `xcheck-theme`；读取或写入异常不影响页面使用。

## 验收

- 无历史选择时页面默认应用微步社区红。
- 右上角可看到并打开皮肤选择器，目录包含六套且仅包含六套皮肤。
- 选择任意皮肤后全站立即变色，刷新或重新挂载后仍恢复该选择。
- 当前情报蓝与原方案的核心色值一致。
- 桌面端和移动端布局正常，前端测试、类型检查和生产构建通过。
